# @arkhe/svelte

[Typeir/arkhe](https://github.com/Typeir/arkhe)

## Use

```svelte
<script>
  import '@arkhe/core/arkhe.css';
  import { ArkheProvider, Button } from '@arkhe/svelte';
</script>

<ArkheProvider>
  <Button icon="plus">New</Button>
</ArkheProvider>
```

## Build

```bash
npm install
npm run build
```
